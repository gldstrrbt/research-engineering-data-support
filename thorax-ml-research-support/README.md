# Thorax ML Research Support

Historical Python work from a thoracic-transplant research-support project.

I did not originate the clinical research question or the collaborator's original notebooks. My work was technical: debugging and restructuring Python, turning repeated notebook work into reusable functions, cleaning and preprocessing data, troubleshooting environments, and helping reorganize exploratory clustering / PCA / H2O model workflows.

The `0_archive/` folder keeps sanitized snapshots of collaborator-supplied starting code so the changes have context. Those files are labeled as collaborator source rather than presented as my original research code.

Large medical/research datasets are intentionally excluded from this public repo. Local paths, personal names, notebook links, and other unnecessary identifiers were also removed from the public copy.
