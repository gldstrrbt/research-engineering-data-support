# Research Engineering & Data Support

A public archive of research-support and data-automation work I built while helping a doctoral researcher with projects that needed more engineering than one-off manual workflows could reasonably handle.

This repo currently contains two recovered bodies of work:

- `app-market-research-automation/` — Python and JavaScript utilities for collecting, cleaning, combining, and reshaping historical Google Play / Similarweb app-market data.
- `thorax-ml-research-support/` — Python work used while troubleshooting and extending a thoracic-transplant machine-learning research workflow.

## Scope

My role was technical support and implementation: debugging Python, cleaning up research code, automating repetitive data work, configuring environments, and turning ad hoc research tasks into scripts that could be rerun.

This is a recovered historical archive, not a polished modern package. Some APIs, page structures, dependencies, and paths are old and may no longer work without changes.

## Public-repo cleanup

Large research datasets, medical data, credentials, cookies, generated exports, and local environment files are intentionally excluded. Historical credential fields are placeholders only.

Where a file began as collaborator-supplied research code, the README in that folder calls that out rather than presenting the underlying research/model design as mine.
